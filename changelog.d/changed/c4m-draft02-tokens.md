- **Breaking:** [`auth`](/docs/config.md#authentication-and-authorization) now accepts only C4M draft 02 tokens (token type `1`, COSE_Mac0/HMAC-SHA256 or COSE_Sign1/ES256). CAT4MOQ tokens are rejected, so existing clients must get new tokens from `moqx-issuer`. `request_update` now requires its own grant, and `subscribe_tracks` is no longer covered by `subscribe_namespace`; sessions without the matching grant get `UNAUTHORIZED` (see the [action names](/docs/config.md#authentication-and-authorization)). A request refused because its token expired now fails with `EXPIRED_AUTH_TOKEN`, and one refused because its token could not be decoded with `MALFORMED_AUTH_TOKEN`, instead of `UNAUTHORIZED` ([details](/docs/config.md#error-codes-for-refused-requests)). The `moqt` claim label is a provisional private-use value.

- [Host and relay tuning guide](/docs/tuning.md) and [`scripts/host-check.sh`](/scripts/host-check.sh), a read-only report of the UDP sysctls, limits, jemalloc and NIC settings on a host or a running relay. `host-check.sh --strict` exits 1 if a sysctl is below the recommended value. Each perf-test run also tries to save the report for both VMs in `run-*.host.txt`; a failed check doesn't stop the run.

- An operator access log: [`logging.access_log`](/docs/config.md#loggingaccess_log) writes one line per session and per MoQT request to a file or stdout, with per-service sink selection, session sampling and nginx-style templates. The access log also writes a `SUB_STATS` line for each sampled subscription every [`periodic_interval_ms`](/docs/config.md#loggingaccess_log).

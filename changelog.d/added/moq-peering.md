- moqx can start [moq-peering](https://github.com/Quicr/moq-peering) instead of MoQ Cluster. `peering.method` selects one method when the process starts. The admin API adds, removes, and restarts a peer and reports each peer's state and metrics. `PUBLISH` and `PUBLISH_NAMESPACE` are announced to peers, and peer announcements are delivered to local `SUBSCRIBE_NAMESPACE` and `SUBSCRIBE_TRACKS` subscribers. Objects follow the same path: a peer subscribed to a local track receives the publisher's objects, and a local subscriber of a peered track receives the objects that peer sends.

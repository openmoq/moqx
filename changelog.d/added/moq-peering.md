- moqx can start [moq-peering](https://github.com/Quicr/moq-peering) instead of MoQ Cluster. `peering.method` selects one method when the process starts, and moq-peering does not also dial service upstreams. The admin API adds, removes, and restarts a peer and reports each peer's state and metrics. `PUBLISH` and `PUBLISH_NAMESPACE` are announced to peers, and peer announcements are delivered to local `SUBSCRIBE_NAMESPACE` and `SUBSCRIBE_TRACKS` subscribers. Objects use the same MoQT subgroup, stream, and datagram encoding as a client session. A subscribe pulls the track when it arrives before the publisher or before the track announce, and the publisher is set to forward=1. When the last subscriber leaves, including while a subgroup is still open, and no local client is still forwarding, the publisher is set to forward=0.

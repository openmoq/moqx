- Config: [`moqt_versions`](/docs/config.md#listeners) accepts 22, so a listener can offer MoQT draft 22. Support is partial: moxygen implements only part of the draft, including the Location Filter and fill fetch. The docker image and `moqx-run.sh` now offer 16, 18 and 22, in that order of preference; a config without `moqt_versions` still offers only 16.
